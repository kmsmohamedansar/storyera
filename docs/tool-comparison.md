# Choose the audit tool by the job

The controlled comparison does not show a winner because these are different layers: **StoryEra audits manuscript continuity, agentrr makes an agent run deterministic, and Retrace provides hosted tracing, replay, and LLM-judge evaluation**. On the local toy workload, StoryEra has concrete evidence—its regression suite passes, its full blind sample finds the three seeded contradictions plus three reconciled/uncertain cases, and a focused fresh-context prefix rerun detects all four seeded prefix cases after an uncertainty-classification instruction fix. No comparable agentrr or Retrace run was executed here, so their latency, cost, trace size, and replay numbers are not fabricated. The recommendation is **continue StoryEra for cited manuscript auditing, and complement it with agentrr or Retrace only if reproducibility/observability is a separate requirement**. Stop StoryEra only if the actual product requirement has changed to generic agent operations rather than continuity review.

## The three tools answer different questions

| Dimension | StoryEra POC | agentrr | Retrace |
|---|---|---|---|
| Primary job | Ordered Markdown continuity audit with ledger, citations, classifications, and repair suggestions | Deterministic record/replay debugger | Hosted trace capture, replay/forking, analytics, and LLM-judge evaluations |
| Same toy-agent output | JSON report grounded in source lines | Replay log and divergence diff | Trace plus optional judge score/regression gate |
| Offline/no-credential path | Yes; instruction-only skill and local Python validator | Yes, after installing the package | Not in this workspace; hosted API needs an `rt_...` key |
| Semantic manuscript judgment | Yes, but model-dependent | No | No native continuity rubric; judge must be supplied |
| Preservation evidence | SHA-256 before/after and unread-scope contract | No manuscript-specific contract | Trace metadata, not source-preservation proof |

agentrr records nondeterministic boundaries—LLM and tool calls, clocks, random draws, and IDs—and replays without live calls or tool side effects; its documented MVP is single-process and synchronous, with concurrency, streaming replay, and multi-agent pipelines out of scope ([agentrr README](https://github.com/ip174/agentrr)). Retrace captures LLM/tool/error spans with token usage, cost, duration, inputs, outputs, and metadata, and documents adapters for common agent frameworks ([Retrace docs](https://docs.retraceai.tech/docs/), [frameworks](https://docs.retraceai.tech/frameworks/)). Its evaluation layer uses weighted LLM-as-judge criteria and flags a regression when average score drops by more than 0.05; batches are capped at 100 traces with concurrency 10 ([evaluations](https://docs.retraceai.tech/evaluations)). These are product/documentation claims, not measurements from this checkout.

## A fair same-agent protocol and the measurements available

The toy agent should read `examples/manuscript/01.md` through `04.md` in order, emit the StoryEra JSON contract, and perform no writes to the manuscript. Run it once from a fresh context, then replay the exact run. Measure wall time, process exit status, output bytes, event/trace count, external-call count, side-effect count, and whether a deliberately changed tool/LLM response is detected at the correct boundary. For StoryEra, additionally measure contract validity, seeded-case matches, source-hash equality, unread-file honesty, and test-suite status. This makes the comparison meaningful without pretending that a replay debugger's “accuracy” is a continuity auditor's accuracy.

The local measurements are reproducible and bounded. `python3 -m unittest discover -s tests -v` passes **26/26 tests**. The checked-in full baseline reports all three seeded contradictions and the three reconciled/uncertain cases; its initial cohort-anchor issue was resolved by broadening the fixture to accept an equivalent citation, not by editing the report. The original prefix baseline still preserves the required separate `author_question` miss for Tess's uncertain bell recollection. After strengthening the instruction, a fresh-context prefix rerun detects all four seeded prefix cases, including the bell question; both reports are retained rather than rewriting the old evidence. SHA-256 was recomputed for all four manuscript chapters before this comparison, and no manuscript changes were made. The local validator checks paths, exact quotes, line ranges, duplicate evidence, classifications, scope partitioning, and hash equality, but it cannot prove exhaustive semantic recall or repair quality ([evaluation guide](evaluation.md)).

The corresponding agentrr metrics are a test plan, not observed values here: record log size and event count; replay wall time and live-call count (expected zero); side-effect count (expected zero); and divergence location after mutating one recorded response. Retrace metrics—ingestion latency, replay latency, token/cost totals, judge score, and regression decision—are **not run** because this workspace has no Retrace credential or configured local server. Its documented 8,000-character final-output and 1,500-character step excerpts also mean a long audit would need an explicit truncation test before treating judge results as equivalent to full-source review ([Retrace evaluations](https://docs.retraceai.tech/evaluations)).

## Decision: continue the audit POC, add operations only when needed

Continue StoryEra if success means “find and explain continuity problems with receipts while leaving the manuscript untouched.” Its strongest differentiators are the source-scoped ledger, paired evidence requirement for contradictions, explicit distinction between contradiction, explained change, intentional mystery, and author question, and preservation/unread-scope checks. The prefix miss is a useful next engineering target—improve uncertainty-to-question coverage and add a second blind sample—rather than evidence that the core POC should be discarded.

Use agentrr as a complement when deterministic reproduction and offline debugging matter; it can wrap the agent that invokes StoryEra but cannot validate the manuscript's facts. Use Retrace when the requirement is production observability, framework integrations, cost/latency analytics, replay/forking, or automated judge gates; it is broader operational infrastructure but requires hosted setup and a separately designed continuity rubric. Do not claim a head-to-head accuracy or speed win until the same toy agent has been executed through all three paths with credentials, identical model/settings, identical input scope, and saved raw artifacts.

## Conclusion

The evidence supports a **continue-with-scope** decision: keep StoryEra as the domain method, measure its known prefix weakness, and treat agentrr/Retrace as instrumentation layers rather than replacements. A true stop decision is justified only if the product brief no longer includes cited manuscript continuity auditing. The next decisive experiment is a credentialed, identical toy-agent run that reports replay overhead and judge behavior separately from StoryEra's semantic findings.
